# Computational Appendix — Proposition C (GOE Splitting-Ratio Typicality)

This repository reproduces every numerical claim in **Section 5 ("Proposition C, Strengthened: Exact
Typicality Bound on the Magnitude of Breaking")** of:

> S. Materov, *On the Impossibility of Deriving Quantitative Intra-Multiplet Splittings from
> Symmetry-Complete Dynamics Alone: A General No-Go Theorem*, 2026.

It supersedes the original Proposition C (20,000 Monte Carlo samples, no independent cross-check, no
uncertainty quantification) with:

1. An **exact, closed-form distribution** for the *d* = 2 splitting-ratio, derived analytically and
   verified two independent ways (large-*N* Monte Carlo and deterministic numerical quadrature that
   does *not* rely on the same substitution used in the derivation).
2. A **quantified, high-precision Monte Carlo scan** for *d* = 2..6, showing that the typical splitting
   ratio grows systematically with multiplet dimension — a finding absent from the original text.

## What each script proves, and why there are three of them

A single script that both derives and checks a formula proves nothing — if there is an algebra error,
the same error would appear in the "check." The three components below are deliberately independent:

| Script | Method | Independent of the derivation? |
|---|---|---|
| `exact_formulas.py` | Closed-form algebra (the result itself) | — (this *is* the claim) |
| `quadrature_verification.py` | Deterministic 2D numerical integration directly over `(m, r)`, **without** using the `v = r/|m|` substitution that produces the closed form | Yes — different method, same underlying joint density |
| `monte_carlo_d2.py` | Direct simulation: draw GOE(2) matrices, diagonalize, form the ratio empirically | Yes — makes no use of any analytic step at all |

Agreement across all three (to 5+ significant figures for quadrature, to Monte Carlo noise for
simulation) is the actual evidence that Section 5.2 of the paper is correct, not just internally
consistent.

```bash
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt

```

Expected total runtime: a few minutes (dominated by the 20M-sample Monte Carlo run and the 3M×5

```bash
python3 src/exact_formulas.py                      # instant
python3 src/quadrature_verification.py              # ~5 seconds

```

## Key numbers (d = 2, exact)

| Quantity | Value |
|---|---|
| Median splitting ratio R | √7 ≈ 2.6458 |
| 90th percentile of R | √199 ≈ 14.1067 |
| 99th percentile of R | √19999 ≈ 141.4178 |
| P(R > 20) | √(2/401) ≈ 7.0622 % |
| P(R > 200) | √(2/40001) ≈ 0.7071 % |

Derivation: `M = [[x,z],[z,y]]`, `x,y ~ N(0,σ²)`, `z ~ N(0,σ²/2)` (the O(2)-invariant, maximum-entropy
GOE(2) normalization — see Section 5.1 of the paper for why this specific normalization is the unique
correct "symmetry-neutral prior," not an arbitrary convention). Writing eigenvalues as `λ = m ± r`, one
finds `m` and `r` independent (`m ~ N(0,σ²/2)`, `r ~ Rayleigh(σ²/2)`), and the ratio `v = r/|m|` has the
exact density `f(v) = v(1+v²)^(-3/2)`. The splitting ratio `R = max(|λ₁|,|λ₂|)/min(|λ₁|,|λ₂|)` is then a
deterministic function of `v` alone, giving `P(R > r₀) = √(2/(1+r₀²))` for `r₀ ≥ 1`. Full algebra is in
the paper; `exact_formulas.py` implements only the final formulas, `quadrature_verification.py`
re-derives the same tail probabilities by brute-force integration without the `v`-substitution.

## Key numbers (general d, Monte Carlo, 3M samples)

See `results/general_d_table.csv`, generated by `src/general_d_scan.py`. Headline finding: the typical
(median) splitting ratio is **not** dimension-independent — it grows from ≈2.65 at d=2 to ≈5.0 at d=3
to ≈11.8 at d=6. This is the standard extreme-value-statistics effect of taking max/min over more
eigenvalues, and it means the "O(1) is typical" framing in the original Proposition C is only exact at
d=2; for the three-generation flavor case the paper is motivated by, the correct symmetry-neutral
benchmark is a *median* ratio of order 5, not order 1. This is stated explicitly in the revised
Section 5.4 of the paper rather than left implicit.

## Reproducibility notes

- All Monte Carlo scripts take an explicit `--seed` argument; results in the paper use `seed=0`
  (`monte_carlo_d2.py`) and `seed=12345` (`general_d_scan.py`).
- `general_d_scan.py` reports bootstrap standard errors on the median (subsampled bootstrap, 200
  resamples of size ≤200,000) so that Monte Carlo noise in the d>2 table is quantified rather than
  implicit, unlike in the original Proposition C.
- No GPU or special hardware required; the full `run_all.sh` run completes on a single CPU core in
  a few minutes. Runtime is dominated by `eigvalsh` calls on batches of small (≤6×6) matrices, which
  is not a bottleneck at these sample sizes.
